
# Projeto JS

## Descrição
Projeto web desenvolvido como atividade de conclusão do curso,
com o objetivo de demonstrar conhecimentos básicos de lógica
de programação utilizando JavaScript.

O site possui exercícios interativos de cálculos,
verificação de notas, identificação de números e soma.

## Tecnologias utilizadas
- HTML5
- CSS
- JavaScript

## Como executar
1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo index.html em um navegador.
4. Utilize os exercícios disponíveis na página.
